1. Install Tailwind CSS
Open your project folder in the terminal:

npm install tailwindcss @tailwindcss/cli

2. Create src/input.css
Put your Tailwind import inside it:

@import "tailwindcss";

3. Build your Tailwind CSS
Run:

npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css --watch

This generates:

dist/
└── output.css

4. Change your index.html
Remove:

<script src="https://cdn.tailwindcss.com"></script>

and add:

<link rel="stylesheet" href="./dist/output.css">

5. For production
Before deploying to GitHub Pages, run:

npx @tailwindcss/cli -i ./src/input.css -o ./dist/output.css

Then commit the generated dist/output.css to your repository if you're deploying directly from GitHub Pages without a build workflow.
